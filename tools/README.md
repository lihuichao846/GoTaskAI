# 辅助工具包 (Tools)

本目录用于存放 GoTaskAI 项目日常维护、测试和应急处理的各种辅助脚本。
这里的文件不参与主程序 (`main.go`) 的编译，仅在需要时通过命令行独立运行。

---

## 1. 密码强制重置工具 (`reset_pwd.go`)

### 📌 作用
在现代安全架构中，用户的密码在数据库中是不可见的单向哈希值（Bcrypt 加密）。当你作为系统管理员需要强制重置某个用户的密码，或者自己遗忘了测试账号密码时，你无法直接在 Navicat 中把密码改为 `123456`（系统无法识别明文）。

该脚本的作用是：**帮你把你想要的明文密码，转换为系统能识别的 Bcrypt 哈希密文。**

### 🚀 使用方法

1. 打开终端，进入本目录：
   ```bash
   cd tools
   ```
2. 运行脚本，并在后面加上你想要设置的**新密码**（例如：`admin888`）：
   ```bash
   go run reset_pwd.go admin888
   ```
3. 终端会输出一串类似 `$2a$10$xxxxxx...` 的长密文。
4. 打开你的数据库管理工具（如 Navicat），找到 `users` 表。
5. 将目标用户的 `password` 字段替换为你刚才复制的这串长密文，保存即可。

### ⚠️ 注意事项
* 这个脚本**不会直接连接数据库**，它仅仅是一个单纯的“文本 -> 密文”转换器，非常安全。
* Bcrypt 算法每次生成的哈希值都**不一样**（哪怕你两次输入的密码完全相同），这是正常现象，请放心使用。
